# OBS Frontend Assignment

## 🚀 Fitur Utama

- **List User**: Menampilkan data user dalam bentuk Table (Desktop) dan Card (Mobile).
- **Search**: Pencarian user berdasarkan nama atau email secara real-time.
- **Pagination**: Pembatasan tampilan data per halaman (5 user per halaman).
- **Responsive Design**: Antarmuka yang optimal untuk perangkat mobile dan desktop menggunakan Material UI.
- **Unit Testing**: Pengujian komponen menggunakan Jest dan React Testing Library.

## 🛠️ Teknologi yang Digunakan

- **Frontend**: React.js (TypeScript)
- **Build Tool**: Vite
- **Dummy API**: [dummyjson](https://dummyjson.com/users)
- **UI Framework**: Material UI (MUI)
- **State Management**: Zustand
- **Icons**: MUI Icons
- **Testing**: Jest & React Testing Library

## 💻 Quick Start

1. `npm install`
2. `npm run dev` (Aplikasi)
3. `npm run test` (Unit Test)
